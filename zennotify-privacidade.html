CAMADAZEN ZENNOTIFY USB

Política de Privacidade

Versão preliminar revista — 18 de novembro de 2026. Esta política aplica-se à aplicação CamadaZen ZenNotify USB — Gmail e é distinta da Política de Privacidade do website CamadaZen.

1. Responsável e contacto

O CamadaZen é um projeto pessoal desenvolvido em Portugal. Para questões relacionadas com a privacidade e o tratamento de dados pessoais, o contacto é camadazen@gmail.com. A identificação formal do responsável pelo tratamento será completada antes da publicação definitiva desta política.

2. Dados e permissões Google

Quando o utilizador associa voluntariamente a sua Conta Google, o ZenNotify solicita a permissão https://www.googleapis.com/auth/gmail.labels. Esta permissão permite consultar e gerir etiquetas Gmail. A versão atual do ZenNotify utiliza-a exclusivamente para consultar a contagem de mensagens não lidas associadas à etiqueta UNREAD. A aplicação não necessita de consultar assuntos, remetentes, corpos de mensagens ou anexos para desempenhar esta função.

3. Finalidade e utilização

A informação consultada é utilizada para apresentar localmente a contagem de mensagens não lidas, atualizar o indicador luminoso RGB associado ao dispositivo USB e informar o utilizador sobre o estado da monitorização. A aplicação consulta periodicamente a API Gmail, normalmente a cada 60 segundos, enquanto a monitorização está ativa.

4. Armazenamento e partilha

Os tokens de autorização Google são armazenados localmente no perfil Windows do utilizador, protegidos através do Windows Data Protection API (DPAPI). A aplicação comunica diretamente com os serviços Google para efetuar as consultas necessárias. O ZenNotify não foi concebido para transmitir dados Gmail para servidores CamadaZen, vender dados pessoais ou utilizá-los para publicidade.

5. Conservação e eliminação

A autorização Google permanece guardada localmente para permitir o funcionamento da aplicação após o encerramento ou reinício do computador, enquanto continuar válida. O utilizador pode utilizar a funcionalidade DESASSOCIAR CONTA GMAIL para eliminar o token de autorização local, depois de parar a monitorização.

Está prevista para o futuro desinstalador uma opção que permitirá escolher entre conservar ou eliminar os dados locais da aplicação. Esta funcionalidade ainda não se encontra implementada.

A eliminação local do token não revoga automaticamente a autorização concedida à aplicação na Conta Google. O utilizador pode gerir ou revogar esse acesso nas definições de segurança da sua Conta Google.

6. Segurança e direitos

O ZenNotify utiliza mecanismos de proteção local dos tokens, incluindo o Windows DPAPI, embora nenhum sistema possa garantir segurança absoluta. Para questões relacionadas com dados pessoais ou com o exercício dos direitos aplicáveis ao abrigo do RGPD, o utilizador pode contactar camadazen@gmail.com. Em Portugal, é possível apresentar reclamação à Comissão Nacional de Proteção de Dados (CNPD).

7. Utilização dos dados Google

Os dados obtidos através das APIs Google destinam-se exclusivamente às funcionalidades descritas nesta política. O ZenNotify não utiliza esses dados para publicidade, venda a terceiros ou finalidades não relacionadas com a monitorização Gmail. A utilização dos dados Google deverá cumprir a Google API Services User Data Policy, incluindo os requisitos de utilização limitada aplicáveis.

8. Alterações à política

Esta Política de Privacidade poderá ser atualizada para refletir alterações técnicas, funcionais ou legais. A versão definitiva será publicada antes da distribuição pública da aplicação, após a confirmação da identificação do responsável e a revisão dos requisitos legais e da Google.
